# SSOT_Explorer — 프로젝트 규칙

마스터본은 이미 자동 로드돼 있다 — `~\.claude\CLAUDE.md`(사용자 레벨)가 `@import`로
세션마다 무조건 주입하므로 따로 찾아가서 읽을 필요 없다. `Local_APP\CLAUDE.md`는
sub-app별 양방향 인덱스 용도 — 이 프로젝트 안에서만 작업할 땐 안 봐도 된다.

## 이 프로젝트 전용 규칙

설계 문서(결정이력+TODO / 레거시+정책맵 / 실행규격서)는 `SSOT_EXP_설계도\` 폴더
안 `SSOT_Explorer_*.md` 3개 파일에 있음(2026-08-13 폴더 분리, Lazzy_App_OS_
Monorepo의 `프로젝트_설계도_SSOT\` 관례와 동일) — v1.0 단일 레포 구조(서브유닛
없음, `설계_방법론_참고.md` §0-A 판단기준 적용: 레포 하나뿐, 나눌 계획 없음).
